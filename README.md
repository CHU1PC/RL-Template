# RL-Template

このリポジトリは、Rust を主言語とする強化学習 Kaggle コンペティション向けの GitHub テンプレートです。
環境シミュレーション、セルフプレイ、探索、エージェントロジックを Rust で実装します。
Python は PPO や AlphaZero などの学習コードに限って使用し、uv で管理します。

## GitHub テンプレートとしての使い方

GitHub のリポジトリページで `Use this template` ボタンを押すか、次のコマンドを実行して新しいリポジトリを作成します。

```bash
gh repo create <name> --template CHU1PC/RL-Template
```
